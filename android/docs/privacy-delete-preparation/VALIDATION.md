# 隐私返回与删除准备优化

2026-10-31

隐私协议保留进入前的设置状态，顶部返回箭头、系统返回及关闭协议均返回设置菜单；从授权页进入仍返回授权页。菜单不与隐私弹窗叠加显示。已验证页面重建后的返回来源。

Android 11+ 批量删除前按存储卷分组，每 200 个 ID 查询一次，使用原有照片签名校验，匹配失败不进入系统删除请求。单卷 2,000 张由 2,000 次逐项校验查询变为 10 次有 ID 限制的查询。批量完成、取消、失败的记录通过事务保存，避免每条独立提交及反复复制整个队列。

Android 8.1–10 仍逐张进行临删除前校验、实际删除和持久回执。单张校验只读签名所需列，避免构造完整照片对象与月份计算，不取消恢复保护。照片多时真实删除和系统自身处理仍需时间；没有在用户照片上做批量删除测速，也没有宣称固定耗时或倍数提升。

验证：51 项单元测试通过（含 2,000 张批量校验并排除变更照片）；API 36 三项设备测试通过（媒体库批量与逐项一致性、变更签名拒绝；事务失败回滚；删除取消/批准/评价状态与隐私返回、系统返回及重建）。Lint 和普通版构建通过。
