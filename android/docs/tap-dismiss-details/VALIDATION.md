# 轻点照片收起详情

日期：2026-10-31。

详情展开时，轻点照片区域收起详情；点详情面板内部或滚动内容不会关闭。沿用同一个手势识别器，只有短按且没有超过拖动阈值、没有多指介入的正常抬手才触发。长按、取消、拖动、缩放及缩放后的剩余单指不会触发收起。

Android 16 / API 36 模拟器共 5 项测试通过：4 项手势专项（包括新增轻点/长按/取消/划动/多指区分），以及照片详情流程（新增面板内点击保留、照片点击收起且不换图；保留原有滚动、返回、照片切换与元数据检查）。测试使用独立 devicetest 应用及生成照片。

普通 Debug 构建及 lint 通过，普通版已覆盖安装到华为 BLA-AL00，安装返回 Success；未清除应用数据。
