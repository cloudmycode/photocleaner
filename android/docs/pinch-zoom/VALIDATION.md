# 双指查看细节（2026-10-31）

- 移除筛选页右上角的 Fill screen / View entire photo 按钮，默认保持完整图片。
- 双指触点中心是缩放锚点；两指同向移动时平移。1–4 倍范围跟手，超出范围有渐进阻尼；少于两指后以阻尼弹簧复原。回弹中再次捏合从当前状态继续。
- 单指划选和双指缩放由同一个识别器处理。一旦出现双指，本次剩余单指不会保留或删除照片；取消触摸也会复原。背景、按钮和日期不跟图片运动。
- 变换在 graphicsLayer 阶段读取，不逐帧重组列表或发起解码。高精度图只在查看期间异步加载，普通预览留在下面避免闪黑。
- 细节解码最长边 4096，并按内存等级限制像素预算（ARGB_8888 估算为内存等级的 1/16，2–24 MiB）；结束后释放该缓存项，不直接无限制解码原图。
- 后一张图按当前图片的显示区域遮挡，解决前横后竖时从黑边露出的情况；划选时随进度展开。
- 核心逻辑集中在 ui/gestures/PhotoGestures.kt、PhotoZoom.kt；缩略图/细节尺寸策略统一在 PreviewPolicy。没有新增权限或依赖。
