# 统一预览勾选与轻音效（1.0.9）

2026-11-01。

## 交互

- 视频和重复/连拍照片预览共用 `RemovalCheckbox`：底部中央的复选框与固定文字 `Mark for removal`。整行可点，提供真实 Checkbox 勾选语义和至少 48dp 触控高度。
- 视频去掉两个大操作按钮。复选框可反复勾选/取消，播放不中断，也不自动退出。
- 月度视频预览关闭时，才提交最终 KEEP/REMOVE 并继续原整理流程；只打开预览再关闭，不产生整理决定。退出按钮和系统返回共用同一提交入口。
- Remove 页视频默认已标记；取消勾选后关闭会走原有恢复保留逻辑。仍勾选则留在待删除列表。
- 视频预览是否打开、当前素材 URI 与未提交选择支持界面重建恢复。相似图片继续复用原有清理选择集合。
- 真正删除仍需要进入既有确认流程；复选框不会立即删除文件。

## 音效

清理完成音效播放增益由 0.65 降为 0.25，保留原音色；不调整手机系统音量。静音、勿扰、其他音频播放和后台时不响等原有条件保持不变。

## 验证

82 项单元测试、普通 Debug 构建、Lint 检查通过。

设备测试使用独立 API 36 模拟器和生成素材，覆盖：预览不操作退出、反复勾选、月度与 Remove 页取消标记、重建恢复、撤销、混合删除确认，以及重复/连拍照片预览选择与截图整理回归。首轮播放测试因同时匹配底层禁用按钮和播放器可用按钮而失败，测试选择器已改为仅匹配可用按钮，针对该项复跑。


复跑时发现 Remove 恢复按钮的 Tooltip 包装丢失了父 Row 的权重约束，导致删除按钮被挤出可见区域。通用图标按钮增加直接参与布局的外层 Box 后修复，测试增加按钮可见性断言。最终视频播放、选择、撤销、混合删除测试通过（68.828 秒）；其余 3 项设备场景首轮通过。共覆盖 4 项设备场景。
