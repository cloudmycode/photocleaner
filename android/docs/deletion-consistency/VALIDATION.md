# 删除后的列表与整理进度一致性

## 修复范围

- 原实现删除成功后移除整理记录，紧接着刷新直接采用 MediaStore 的查询结果。系统若暂时返回旧行，已删除照片会重新进入列表，并因缺少整理记录变成未整理。
- `reviews.db` 升级到版本 2，新增仅含 URI 和内容签名的删除回执表。已确认删除的回执与对应整理记录的移除在同一事务提交；取消、失败和未确认的条目不移除。
- `LibrarySnapshot` 统一过滤内存更新与数据库加载结果。月份封面、照片数量、完成进度、待删除列表及浏览队列都来自过滤后的照片集合。匹配 URI 和签名，避免旧回执影响复用 URI 的不同照片。
- 删除日志只有在回执持久化后才清除。启动时立即核对中断操作中的已确认成功项，不自动重试任何删除。重复处理回执不改变最终结果。
- 保留照片仍可从已完成月份重新浏览，这是既有产品行为；没有未整理的新照片时，月份保持完成状态。
