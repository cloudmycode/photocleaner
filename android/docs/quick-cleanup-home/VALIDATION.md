# 快速清理首页（2026-11-06）

## 行为

- 新启动默认进入 Clean up；媒体读取完成后复用现有本地扫描。恢复已有会话时保留原页面。
- 首页优先推荐重复照片；没有重复候选时推荐连拍。主按钮进入分组复查，不直接删除。
- 容量为推荐类别中额外照片按 URI 去重后的文件大小上限，不跨重复、连拍类别累计，也不把截图总大小当成可释放空间。
- 扫描中不展示旧结果的释放容量。失败显示重试；跳过不可读取照片时标注结果不完整；部分授权时提供管理入口。
- 无候选时引导复查截图或按月整理，不暗示整个相册已清理完成。
- 底部 Clean up 位于第一项；Months 保留完整整理流程，从 Months 返回进入 Clean up。
- 首次授权页说明查找、复查和确认，不再要求先理解滑动手势。
- 不增加照片上传或外部统计服务。
