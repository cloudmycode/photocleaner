# 首页精简、详情入口与缩放优化

日期：2026-10-31。

## 行为

- 最新月份未完成时显示 Start sorting / Continue sorting；完成后隐藏按钮，保留月份、完成标记与进度条。点击整个封面仍可重新浏览。
- 划选页不再单独显示左下角日期；“…”替换到该位置，展开/收起完整照片详情。详情中的日期信息保留。
- 当前照片静止后，在后台准备一份受像素/内存预算限制的高清位图，并预热绘制。手势中、划选动画中、缩放回弹中不切换清晰度；同一照片反复缩放复用位图。
- 前图只绘制一张图，避免此前普通图与高清图叠加；高清图不写入共享缓存，不挤占下张照片预览。切换当前照片/退出页面取消请求并释放持有引用，不手动回收仍可能被绘制的位图。

## 性能检查及限制

旧实现仅在 zoom.active 时创建高清图组件，并在松手后移除、删除缓存，导致每次手势重新请求高清图，同时发生两张图叠加绘制。新实现将准备过程移至静止期并在当前照片生命周期内复用。

新增 PinchPerformanceTest 使用真实时钟、连续 8 次双指输入及系统 FrameMetrics。真机旧版两次测量均被华为 HiAction 服务崩溃打断：系统明确记录因依赖崩溃的 HiActionManagerProvider 而杀死测试应用（见 phone-system-interference.txt），没有取得有效的前后性能对比。没有禁用/修改手机系统服务。

模拟器测量仅作为实验记录，不能代表手机实际帧率；其图形渲染时间远高于应用 UI 处理时间，因此不据此宣称稳定 60 fps 或具体真机性能提升。应用内功能测试正常通过，但系统双指识别服务的干扰尚未消除。

模拟器连续 8 次缩放均完成且无误整理：旧版 575 帧 / P95 总时长 297.51 ms / P95 UI 处理 7.51 ms；新版 588 帧 / P95 总时长 238.82 ms / P95 UI 处理 7.56 ms。以上含模拟器渲染开销，不作为真机帧率结论。原始记录见 emulator-before.json、emulator-after.json。
