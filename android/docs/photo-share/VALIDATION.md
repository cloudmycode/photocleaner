# 划选页分享当前照片

2026-10-31

- 最底部工具栏依次为撤销、分享、待删除；使用同一套线条图标和浅色圆形底。分享按屏幕中心对齐，不受右侧数量宽度影响。
- 点击后打开 Android 系统分享面板，只传递当前照片；返回或取消不改变当前照片、Keep/Remove 决定及浏览位置。
- 分享前在 IO 线程核对 URI、内容签名和文件可读性；只分享 MediaStore 图片 URI。不复制或重新压缩照片，不新增权限或网络能力。
- `ACTION_SEND` 设置实际图片 MIME、单个 `EXTRA_STREAM` 与 ClipData，使用临时只读 URI 权限；不授予写入、永久或目录权限。
- 划动、缩放、保存或准备分享时禁用相关按钮；准备分享时也阻止新的照片手势。返回应用保留原整理进度，离开划选页时取消尚未完成的分享准备。

验证：62 项单元测试通过；API 36 模拟器的 4 项设备测试通过，覆盖当前照片只读分享、分享面板打开/取消、下一张照片分享、连续反向划动及双指缩放。模拟器截图使用独立测试版生成图片。测试没有选择真实联系人或向第三方发送图片。

华为 BLA-AL00（Android 8.1 / API 27）分享的 2 项测试通过，连续反向划动及双指缩放也通过。首轮测试发现华为系统的 chooser action 与标准名称不同，测试已按系统工厂实际返回值匹配；生产代码仍使用系统分享面板，无华为专用分支。另一次截图时出现划动中的画面，随后分享按钮查找失败；未修改代码重跑同一测试通过，保留原始日志。
