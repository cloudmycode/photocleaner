# 照片大小、详情浮层与图片圆角

日期：2026-10-31。

## 实现

- 划选照片区域右下角显示当前文件的 B / KB / MB / GB 大小，与左下角“…”垂直对齐，切换照片时跟随更新。复用详情内的大小格式，未知值显示破折号。
- 详情从“每次打开读取、排版全部字段、高度随加载变化”改为：当前照片静止后后台读取，只缓存当前照片；切换照片/文件签名/权限版本立即失效；固定 240 dp 可滚动区域；LazyColumn 只排版可见项；160 ms 淡入、120 ms 淡出，不做高度扩展动画。
- 背景不透明度由 240/255（约 94%）降至 179/255（约 70%）。不增加模糊或屏幕采样开销。
- FittedPhotoShape 根据照片实际 Fit 矩形裁剪 22 dp 圆角，使用解码后图片的宽高，避免媒体库尺寸缺失或 EXIF 旋转信息导致裁剪错误。预览和高清图片共用形状，裁剪位于照片变换内，随划选、缩放移动。外层黑色舞台仅进行矩形越界裁剪。下一张照片的遮罩同样匹配前图圆角，避免从圆角处漏出。
- 不改缩放焦点、手势阈值、图片内存预算和照片文件本身。
